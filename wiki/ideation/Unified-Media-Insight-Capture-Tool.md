# Unified Media Insight Capture Tool

## Problem Statement
When I encounter a moment of insight inside media I'm consuming (a musical effect, a sentence in an article, a video snippet), I want to capture that specific idea with my own commentary and a tag, so I can retrieve and build on it later — as opposed to just archiving the source itself.

## Core User Flow
1. **Trigger** — user is consuming media (song, article, video) and hits a moment of insight.
2. **Capture** — user saves a reference to that specific moment (timestamp, sentence, clip) — *not* the whole media object.
3. **Annotate** — user adds a comment/idea (why it mattered) + a hashtag/tag.
4. **Archive** — the annotated idea lives in a personal collection.
5. **Retrieve** — later, user browses/searches by tag or theme.
6. **Extend** — user uses the retrieved idea as a seed for new writing/composition/creation.

## Market Gap
Most tools serve specific niches (text, audio, or podcasts). There is no single service that spans song, article, video, and podcast uniformly where every capture is a "timestamp/quote + your idea + tag" object model.

## References
- [[https://read.readwise.io/|Readwise Reader]]: Strong reference for the "archive everything" experience, though primarily focuses on text/content rather than "idea-first" capture.
- [[https://are.na/|Are.na]]: Useful for compiling web-clipped or uploaded "blocks" (links, images, text) into channels, acting as a "playlist for ideas."
- [[https://mymind.com/|mymind]]: AI-first "save anything, organize nothing" space using AI to interpret content for future retrieval.
- [[https://snipd.com/|Snipd]]: Mature tool for marking moments mid-playback, capturing transcripts, and syncing notes.
- [[https://ondao.io/|Onda]]: Audio-focused "music diary" for capturing insights with timestamps, reflections, and export capabilities.
